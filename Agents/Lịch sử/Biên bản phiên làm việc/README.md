# Biên bản phiên làm việc (Session Reports)

## Mục đích
Ghi lại kết quả, quyết định thiết kế và danh sách tệp thay đổi sau mỗi phiên làm việc để giúp lưu trữ lịch sử và phân tích lỗi nếu xảy ra sự cố.

## Cách sử dụng
- Cuối mỗi phiên làm việc, chạy lệnh `/end-session` để tự động tạo một biên bản mới tại thư mục này với định dạng `YYYY-MM-DD.md` (hoặc `YYYY-MM-DD-TênAI.md`).
- AI Agent ở phiên tiếp theo có thể đọc biên bản gần nhất để hiểu lịch sử thực thi gần đây.
