# Tài liệu Nghiệp vụ (Business Documentation)

Thư mục này chứa các tài liệu phân tích nghiệp vụ, mô tả luồng hoạt động và quy tắc vận hành từ góc nhìn sản phẩm (Product/Business logic) của dự án **Court Management System**.
